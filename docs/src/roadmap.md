Roadmap for the Openhost team - what is done and what we are planning to work on in the future.


last updated 8/10/26



things that are considered mostly finished/stable (issues in these are high priority to fix):
- compute space core
- service interface
- catalog + current apps in catalog
- basic imbue managed spaces platform

things being worked on / polished up now:
- more polished design/branding/UX for all surfaces
- great docs
- public landing page, with public docs, and clear onboarding flow for selfhost or managed
- great self-hosted onboarding

roadmap (likely to happen):
- add openhost platform support for notifications
- get notifications working in community chat app
- email auto-setup in new spaces
- share apps with others via email address (with email magic link auth)
- imbue managed services
  - IP tunnels
  - s3
- pre-setup raspberry pis that we can give out
- cloud in a bottle newsletter, showing off cool new stuff each ~week
- polished coding-in-openhost apps (VS code, claude code, sculptor, minds, etc)
- many more great apps!
  - some specific examples:
    - viable google sheets alternative
- have a free tier in our managed service, with limited memory and auto-suspending of apps or whole space

roadmap (speculative):
- inspirations catalog channel - for apps that aren't as polished/serious but still cool to share
- platform support for peering between multiple compute spaces owned by a single user, where they appear to the user as one unified space. to allow higher availability or other features
